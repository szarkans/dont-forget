# don't forget — правила работы над проектом

Холодный старт: читай `START.md`. Спека — `SPEC.md`. Справочник по mnemo — `MNEMO.md`,
а сам mnemo установлен и читается: `~/.claude/plugins/cache/mnemo/mnemo/1.2.14/`.

## Восемь правил, которые здесь уже оплачены

1. **Метки источника.** Утверждение в спеке помечается `[замер]`, `[Серёжа]`,
   `[отчёт]` или `[моё]`. Метка `[Серёжа]` и слова «так сделано в mnemo» иммунитета
   не дают: замер их опроверг — сказать вслух, а не замять. Уже сработало —
   «7,5 сессий/день» из отчёта оказались чужой цифрой, у Серёжи 1,7.

2. **Правило остановки.** Новый артефакт нужен, чтобы починить поведение
   предыдущего? Вернуться на уровень выше и упростить предыдущий, а не строить ещё
   один снизу. У mnemo этот сигнал прозвучал четыре раза — так и выросла сага
   handoff → index → archive → resolver → пять миграций.

3. **Нет измеренной проблемы — нет фичи.**

4. **До запуска проверки сказать, что будет значить каждый исход.** Не можешь
   сформулировать заранее — проверка декоративная, не запускай и как довод не
   показывай.

5. **Размер скилла — метрика.** Шаг разросся больше десяти строк — выносить в
   скрипт. Тело скилла пишется инструктажем («что делаешь, почему так устроено,
   где ловушки»), а не процедурой («Шаг 1, Шаг 2, таблица режимов») — процедура
   превращает агента в робота, который встаёт колом на всём, чего нет в таблице.

6. **Скиллы плагина — на английском.** Плагин опен-сорс, для всех. Русским
   остаётся только то, что читает Серёжа: CLAUDE.md, PLAN.md, BACKLOG.md,
   задачи в tasks/.

7. **Description скилла — короткий.** Description зацепляет триггеры
   и называет результат в двух-трёх предложениях, а не описывает скилл целиком.
   Ориентир объёма: description `about` был ~90 слов и ужат примерно на четверть.
   Числа — ориентир, не норма: важна плотность, а не счёт слов.

8. **Скиллы безликие.** Ни имён («Серёжа»), ни личных привычек, ни личного
   контекста: тот, кто поставил плагин, — «user». Персонализация живёт только
   в личных файлах Серёжи (CLAUDE.md, PLAN.md, BACKLOG.md, tasks/).
