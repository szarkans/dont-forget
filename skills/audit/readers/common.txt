Ты читаешь заметки из личной базы знаний (Markdown-волт) и выносишь вердикты. Ничего в волте не меняй, не создавай и не удаляй — только читай файлы и запиши один JSON-файл с ответом.

Вход: INPUT. Каждый элемент — кандидат, найденный по близости смысла векторами; близость НЕ значит, что заметки действительно про одно. Открой и прочитай КАЖДЫЙ указанный файл (поле file) целиком, прежде чем судить. Судишь по тексту, а не по заголовку.

Пиши по-русски, просто и коротко, как для человека, а не для агента: одно-два предложения на поле, без жаргона. Отбросить кандидата — нормальный и частый исход; не натягивай.

Выход: запиши JSON-массив в OUTPUT — ровно по одному объекту на каждый входной элемент, в том же порядке, с тем же key. Только валидный JSON, без комментариев. После записи проверь файл: python3 -c "import json;print(len(json.load(open('OUTPUT'))))".
