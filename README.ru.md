# Don't forget

*I'm with you in the dark.*

Долговременная память для ИИ-агентов — заметки в стиле Zettelkasten, обычный Markdown,
как в Obsidian.

Вдохновлено [mnemo](https://github.com/jojoprison/mnemo).

🌍 [English](README.md) · [中文](README.zh.md)

## О чём это вообще

Папка `.md`-файлов, куда складывается каждая грабля, передача сессии, идея или факт,
на которые ты наткнулся в работе и решил (или твой агент решил) сохранить.

Потом можно вспомнить: «о, мы же это делали два года назад!» или «стоп, вот это два
месяца назад развалило нам базу». Поиск работает локально — полнотекстовый SQLite
плюс обход `[[вики-ссылок]]` между заметками. Иногда находится то, что писалось совсем
по другому проекту.

> А чем не устраивает claude-mem / другой плагин памяти?

claude-mem — быстрая память (как оперативка), агент видит её всегда. dont-forget —
долговременная (как жёсткий диск), и для тебя, и для агента.

## Установка

**1. Поставить плагин.** В Claude Code:

```
/plugin marketplace add szarkans/dont-forget
/plugin install dont-forget@dont-forget
```

Или из терминала:

```bash
claude plugin marketplace add szarkans/dont-forget
claude plugin install dont-forget@dont-forget
```

**2. Показать, где лежат заметки.** Запусти `/dont-forget:setup`. Он читает список
волтов самого Obsidian, показывает, что нашёл, и записывает конфиг после твоего
выбора — путь руками вбивать не надо.

Подойдёт любая папка с `.md`-файлами. Obsidian не нужен — это просто папка, а если
сетап ничего не найдёт, он примет путь, который ты назовёшь.

**3. Перезапустить Claude Code.** Индекс соберётся сам при первом поиске и дальше
поддерживает себя сам. Руками запускать нечего.

Нужен только `python3`. Никаких pip-установок и зависимостей — одна стандартная
библиотека.

> **Не через `npx skills add`.** Тот инструмент копирует только папку скилла. Скиллы
> этого плагина вызывают скрипты из `scripts/` и ставят хук на старте сессии — ни то,
> ни другое туда не попадает, и скиллы падают при первом же вызове. Это замерено, а не
> предположено. Ставь через маркетплейс, как выше.

## Производительность

На WSL2 держи волт на линуксовой файловой системе, а не под `/mnt/c`. Замерено на
волте из 760 заметок: обновление индекса без изменений — ~85 мс на ext4 против ~6 с
на `/mnt/c` (drvfs/9p штрафует за каждый файл отдельно). У хука `SessionStart` таймаут
10 с, так что волт на `/mnt/c` съедает большую часть этого бюджета ещё до старта.

## Команды

`/dont-forget:this` — «слушай, давай сохраним этот факт/граблю/решение, чтобы не
забыть». Пишет атомарные заметки и проверяет, нет ли такого в волте уже.

`/dont-forget:about` — «а почему мы вообще переехали на postgres?», «что тут было не
так?». Ищет по волту и отвечает с цитатами и честным отчётом о покрытии — в том числе
прямо говорит, когда по твоему вопросу в волте нет ничего.

`/dont-forget:session` — скилл конца сессии. Записывает, что сделали, в заметку сессии
и индексирует её открытые хвосты, чтобы следующая сессия их подхватила.

`/dont-forget:review` — оглядывается на сессию и проверяет её: что реально сделано, что
только объявлено сделанным, какие факты и обещания не доехали до памяти.

`/dont-forget:checkup` — здоровье **волта**: коммитит его в git и показывает, что
на самом деле видит индекс.

`/dont-forget:setup` — показывает плагину, где твои заметки, или переводит его на
другую папку потом. Находит волты сам, вместо того чтобы просить путь.

`/dont-forget:feedback` — записывает доказанные промахи и попадания поиска, чтобы
чинить поиск по фактам, а не по ощущениям.

## Что делает само

В начале каждой сессии подставляет открытые хвосты за последние 7 дней — незакрытые
чекбоксы из заметок сессий. Команда не нужна.

И подаёт голос перед автокомпактом Claude Code — моментом, когда живой диалог
заменяется пересказом. Просит агента сохранить сессию, пока на это ещё есть место,
а не когда окно уже кончилось. Заговорит и сильно раньше, когда контекст просто
вырос настолько, что ответы становятся хуже, и предложит начать заново — предложит,
сам ничего не чистит.

По умолчанию он *предлагает* и ждёт: сохранение пишет заметки и коммитит волт, а хук
срабатывает по расписанию, о котором ты не просил, — значит решаешь ты. Хочешь, чтобы
просто делал: `"autocompact_autosave": true` в `~/.dont-forget/config.json`.
Не надо вообще ничего: `"autocompact_nudge": false` там же.
