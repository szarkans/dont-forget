# Don't forget

*I'm with you in the dark.*

Персистентная память для Claude Code: Zettelkasten-заметки в Obsidian-волте,
автоматический recall на старте сессии, поиск по словам и по смыслу с обходом
графа связей.

Наследует концепцию [mnemo](https://github.com/jojoprison/mnemo) (MIT).
Архитектура своя. Приватный проект, не для marketplace.
