# Don't forget

*I'm with you in the dark.*

Долговременная память для ИИ-агентов — заметки в стиле Zettelkasten, обычный Markdown,
как в Obsidian.

Вдохновлено [mnemo](https://github.com/jojoprison/mnemo).

🌍 [English](README.md) · [中文](README.zh.md)

## О чём это вообще

Папка `.md`-файлов, куда складывается каждая грабля, передача сессии, идея или факт,
на которые ты наткнулся в работе и решил (или твой агент решил) сохранить.

Потом можно вспомнить: «о, мы же это делали два года назад!» или «стоп, вот это два
месяца назад развалило нам базу». Поиск работает локально — полнотекстовый SQLite
плюс обход `[[вики-ссылок]]` между заметками. Иногда находится то, что писалось совсем
по другому проекту.

> А чем не устраивает claude-mem / другой плагин памяти?

claude-mem — быстрая память (как оперативка), агент видит её всегда. dont-forget —
долговременная (как жёсткий диск), и для тебя, и для агента.

## Установка

```
/plugin marketplace add szarkans/dont-forget
/plugin install dont-forget@dont-forget

or
claude plugin marketplace add szarkans/dont-forget
claude plugin install dont-forget@dont-forget
```

потом

`/dont-forget:setup`

потом

Дальше просто пользуйся Claude Code как обычно. Через какое-то время у тебя появится
что-то вроде второго мозга.

Нужен только `python3`. Никаких pip-установок и зависимостей — одна стандартная
библиотека.

## Команды

`/dont-forget:that` — «слушай, давай сохраним этот факт/граблю/решение, чтобы не
забыть». Пишет атомарные заметки, предупреждает, если в заметку затесалось что-то
похожее на секрет, и останавливается спросить, когда в волте уже есть заметка про то же.

`/dont-forget:about` — «а почему мы вообще переехали на postgres?», «что тут было не
так?». Ищет по волту и отвечает с цитатами и честным отчётом о покрытии — в том числе
прямо говорит, когда по твоему вопросу в волте нет ничего.

`/dont-forget:session` — скилл конца сессии. Свежие суб-агенты читают транскрипт сессии
и приносят список того, что не доехало до памяти; пока ты не скажешь — ничего не
пишется. Дальше записывает заметку сессии, гасит хвосты, про которые есть улика, и
проверяет волт.

`/dont-forget:health` — здоровье **волта**: коммитит его в git и показывает, что
на самом деле видит индекс.

`/dont-forget:audit` — долгое чтение, изредка: заметки, у которых мог наступить
назначенный им срок смерти; заметки, которые всё время отвечают на одни и те же вопросы
и, может быть, об одном; имена, на которые волт всё ссылается и ни одной заметкой не
отвечает. Предлагает — решаешь ты.

`/dont-forget:setup` — показывает плагину, где твои заметки, или переводит его на
другую папку потом. Находит волты сам, вместо того чтобы просить путь.

## Что делает само

В начале каждой сессии подставляет два коротких списка по проекту, в котором ты сидишь:
самые свежие открытые хвосты — незакрытые чекбоксы из заметок сессий — и самые свежие
грабли, то есть не «что сделать», а «обо что бьются». По пятнадцать штук, остальное
достаётся поиском. Команда не нужна.

Ещё тебя предупредят, когда автокомпакт близко, и предложат прогнать
`/dont-forget:session` — чтобы не потерять прогресс и оставить хороший хэндофф
для новой сессии.
